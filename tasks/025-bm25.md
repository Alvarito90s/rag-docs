# 025 · Tokenizador e índice BM25
Fase: 2 · Depende de: ninguna

## Objetivo
Búsqueda por palabras clave con BM25 (`rank-bm25`), para nombres propios, códigos y siglas que los embeddings fallan.

## Decisión de diseño
El índice BM25 NO se guarda en disco: se construye en memoria a partir de los chunks de la base vectorial (`VectorStore.all_chunks()`) al arrancar la búsqueda. Así hay una única fuente de verdad y BM25 nunca queda desincronizado de Chroma. Construirlo para miles de chunks tarda milisegundos.

## Interfaz
```python
import re
import unicodedata
from collections.abc import Sequence

from rank_bm25 import BM25Okapi


def tokenize(text: str) -> list[str]:
    """Minúsculas, sin tildes, palabras alfanuméricas: 'Garantía SKU-4471' -> ['garantia', 'sku', '4471']."""


class Bm25Index:
    """Índice BM25 en memoria sobre (id, texto)."""

    def __init__(self, ids: Sequence[str], texts: Sequence[str]) -> None: ...
    def __len__(self) -> int: ...
    def search(self, query: str, k: int) -> list[tuple[str, float]]: ...
```

## Comportamiento
1. `tokenize`: `unicodedata.normalize("NFKD", text)`, quita los caracteres con `unicodedata.combining(c)`, pasa a minúsculas y devuelve `re.findall(r"\w+", texto)`.
2. `__init__`: si `len(ids) != len(texts)` → `ValueError`. Guarda los ids, los tokens de cada texto y su conjunto (`set`). Si hay al menos un texto, `self._bm25 = BM25Okapi(lista_de_tokens)`; si no, `None` (`BM25Okapi` falla con un corpus vacío).
3. `search`:
   a. Si `k <= 0`, el índice está vacío o `tokenize(query)` está vacío → `[]`.
   b. `scores = self._bm25.get_scores(tokens_consulta)`.
   c. Candidatos: SOLO los documentos que contienen al menos un token de la consulta (intersección de conjuntos). No filtres por `score > 0`: BM25Okapi da IDF 0 a un término presente en la mitad del corpus, y ese documento sí es relevante.
   d. Ordena por puntuación descendente y, a igualdad, por posición original; devuelve los `k` primeros como `(id, float(score))`.

## Tests obligatorios
`tests/index/test_bm25.py`. NO cambies los valores esperados.
Corpus del test:
```python
IDS = ["c1", "c2", "c3", "c4"]
TEXTS = [
    "El proveedor ofrece una garantía de dos años.",
    "El depósito de agua tiene 1,8 litros.",
    "El código de error E-17 indica depósito vacío.",
    "Referencia interna SKU-4471-B del filtro.",
]
```
1. `tokenize("Garantía de DOS años, SKU-4471-B!")` → `["garantia", "de", "dos", "anos", "sku", "4471", "b"]`.
2. `tokenize("¿Qué pasa?")` → `["que", "pasa"]`; `tokenize("")` → `[]`.
3. `search("garantia", 5)` → un resultado, `"c1"`, con puntuación `pytest.approx(0.8473, abs=1e-3)`.
4. `search("Garantía", 5)` → mismo resultado que el 3 (tildes y mayúsculas no importan).
5. `search("E-17", 5)` → solo `"c3"`.
6. `search("sku 4471", 5)` → solo `"c4"`.
7. `search("deposito", 5)` → ids `["c2", "c3"]` (los dos contienen el término aunque su puntuación sea 0).
8. `search("el de", 5)` → ids `["c1", "c2", "c3"]` (c1 y c2 empatan y se respeta el orden original); `search("el de", 1)` → `["c1"]`.
9. `search("xyz", 5)` → `[]`; `search("", 5)` → `[]`; `search("garantia", 0)` → `[]`.
10. `Bm25Index([], [])` → `len == 0` y `search("algo", 5) == []`.
11. `Bm25Index(["a"], [])` → `ValueError`.
