# Apuntes de redes

## Modelo OSI

El modelo OSI divide la comunicación en siete capas: física, enlace, red, transporte, sesión, presentación y aplicación.

## Puertos habituales

| Protocolo | Puerto | Transporte |
| --- | --- | --- |
| SSH | 22 | TCP |
| SMTP | 25 | TCP |
| DNS | 53 | UDP |
| HTTPS | 443 | TCP |

## TCP frente a UDP

TCP garantiza la entrega ordenada de los segmentos; UDP no.
